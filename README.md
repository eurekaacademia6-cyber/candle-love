# Quotex Next Candle AI - Real Vision 2.0

This is a standalone camera-only analysis app. It does not connect to Quotex, place trades, or click buttons.

The critical change is real visual candle detection and a hard prediction gate. The model does not run unless at least 10 visible candle bodies are detected with acceptable quality.

The shipped predictor is a transparent research baseline, not a claim of a proven win rate. Use the included historical training pipeline to train and validate a real model before treating probabilities as predictive statistics.
